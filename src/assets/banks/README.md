# Bank badge artwork

These compact marks are icon-only crops from the approved third badge row of
`docs/ui/bank-badge-treatment-exploration.png`. They are bundled locally so the
application never fetches bank artwork at runtime.

- `bac.png`
- `banco-general.png`
- `davivienda-badge.png`
- `promerica.png`

Each file includes the complete centered circular treatment. The Davivienda
asset uses a tighter, centered crop of the same third-row artwork because the
original composition has more internal padding than the other three.
